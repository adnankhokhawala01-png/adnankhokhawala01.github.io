# Adnan Khokhawala — Portfolio Site

A clean, minimal portfolio site built from your resume. White background with
Rutgers scarlet and dark navy accents.

## Files
- `index.html` — page content and structure
- `styles.css` — all styling
- `script.js` — mobile menu toggle

## Deploy with GitHub Pages
1. Create a new public repository on GitHub, for example `portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root
   (drag and drop on the GitHub website works, or use `git add`, `git commit`,
   `git push` from your computer).
3. In the repository, go to **Settings > Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**,
   pick the `main` branch and the `/ (root)` folder, then click **Save**.
5. Wait one to two minutes, then refresh the Pages settings page. Your live
   link will appear at the top, usually
   `https://YOUR-USERNAME.github.io/portfolio/`.

## Before you publish
- Update the LinkedIn link if it changes.
- Swap the placeholder "View on LinkedIn" links under each experience entry
  for a real project link, write up, or company page if you have one.
